# 9-ball

> **Looking for the Ollama model and hardware catalog? That's [8-ball](https://github.com/terminal-glass/8-ball).** 9-ball is the agentic build.

9-ball is a very lightweight installer for emergency-services help in Africa. It lets AI agents send email to each other over a new protocol for AI bots.

More details are coming soon.
